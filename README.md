# 생윤 단서 추적 SRS

지문형 표현으로 사상가를 역추적하는 간격 반복(Leitner box) 학습 앱.

## 배포 (GitHub Pages)

1. 새 저장소 생성 (예: `saengyun-srs`)
2. 이 폴더 안 파일(`index.html`, `manifest.json`, `sw.js`, `icon.svg`) 그대로 저장소 루트에 업로드
3. 저장소 **Settings → Pages → Branch: main / (root)** 선택 후 저장
4. 잠시 후 `https://<아이디>.github.io/saengyun-srs/` 로 접속
5. 모바일 브라우저에서 접속 후 "홈 화면에 추가"하면 앱처럼 아이콘이 생기고, 이후 오프라인에서도 열림

## 동작 방식

- 하루를 아침/저녁 2세션(오후 3시 기준)으로 나눠서 관리
- 각 사상가 카드는 box 1~5로 관리되고, 맞히면 다음 복습까지 간격이 늘어남(다음 세션→1세션 후→2세션 후→3세션 후→5세션 후, 즉 최대 2.5일)
- 틀리면 box 1로 돌아가고 같은 세션 안에서 곧 다시 나옴
- 이 간격은 7일(=14세션) 안에 전체 카드가 여러 번 순환되도록 맞춰져 있음 — 시험이 임박했을 때 쓰기 좋은 촘촘한 주기
- 학습 기록은 브라우저 로컬(localStorage)에 저장되어, 껐다 켜도 유지됨 (기기별로 별도 저장)
